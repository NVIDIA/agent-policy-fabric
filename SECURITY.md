# Security

NVIDIA is dedicated to the security and trust of its software products and
services, including open-source projects.

Do not report security vulnerabilities through public issues, pull requests,
pull requests, discussions, or social channels. If a potential security issue
is reported publicly, maintainers may limit discussion and redirect the
reporter to NVIDIA's private disclosure channels.

## Reporting a potential security vulnerability

Report a potential vulnerability in APF through one of these NVIDIA Product
Security Incident Response Team (PSIRT) channels:

- Web: [Security Vulnerability Submission Form](https://www.nvidia.com/object/submit-security-vulnerability.html)
- Email: <psirt@nvidia.com>
- Encryption: [NVIDIA public PGP key](https://www.nvidia.com/en-us/security/pgp-key)

Include, when available:

- The affected APF version, branch, tag, or commit.
- The vulnerability type and affected component.
- Reproduction instructions and proof-of-concept code.
- Potential impact and exploitability.
- Known mitigations and whether the issue is already public.

Coordinate disclosure with NVIDIA PSIRT and do not publish exploit details
until a fix or mitigation is available. See NVIDIA's
[PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/) for
additional information.

## Supported versions

APF is under active development. Security fixes are currently provided for the
