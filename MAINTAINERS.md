# APF Maintainers

This file records project ownership for NVIDIA Agent Policy Fabric (APF).

| Maintainer | GitHub | Scope |
| --- | --- | --- |
| Divya Vavili | [@dvavili](https://github.com/dvavili) | Project-wide maintenance and code ownership |

At least one maintainer should review substantive changes before merge.
Changes affecting policy semantics, signing, governance, security,
compatibility, or supported deployment surfaces require an accepted scope
decision before implementation.

Maintainer changes should be proposed through a pull request and approved by
an existing maintainer.
