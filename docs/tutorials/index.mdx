Each tutorial sets up one governance scenario end to end: the setup, the policy, the behavior you should see, and the audit evidence that proves it. The scenarios are introduced in [Use Cases](../about/use-cases.mdx).

Start with [Your First Signed Policy](../get-started/your-first-signed-policy.mdx) and [Your First Governed Agent](../get-started/your-first-governed-agent.mdx). The tutorials assume APF is running and registered with OpenShell as described there.

Give a coding agent read-only source control, approved inference endpoints, and nothing else.
</Card>

- To change a rule and roll it out without a restart, refer to [Update a Signed Policy](update-a-signed-policy.mdx).
- To see how APF refuses a modified bundle, refer to [Reject a Tampered Bundle](reject-a-tampered-bundle.mdx).
